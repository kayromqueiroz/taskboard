# TaskBoard

O projeto permite organizar tarefas por etapa, prioridade e prazo em uma interface simples de produtividade.

## Funcionalidades

- Cadastro de tarefas com titulo, descricao, status, prioridade e prazo.
- Edicao e exclusao individual de tarefas.
- Colunas Kanban: A fazer, Fazendo e Concluido.
- Arrastar e soltar tarefas entre colunas.
- Etiquetas por tarefa.
- Filtro por busca, prioridade e etiqueta.
- Indicador visual de tarefas atrasadas.
- Resumo com contadores por status e alta prioridade.
- Persistencia no navegador usando `localStorage`.
- Layout responsivo para desktop e celular.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Drag and Drop API

## Como executar

Abra o arquivo `index.html` no navegador.

## Objetivo do projeto

Este projeto foi criado para praticar interfaces interativas e gerenciamento de estado no front-end. Ele demonstra manipulacao do DOM, eventos, filtros, persistencia local, responsividade e uso da Drag and Drop API.
